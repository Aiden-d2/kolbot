# 프레임 (패스트 캐스트·패스트 히트 리커버리·패스트 블록, 어쌔신 공속)

직업별 패스트 캐스트(패캐)·패스트 히트 리커버리(패힛)·패스트 블록(패블럭) 프레임과, 어쌔신 스킬별 공격 속도 (261104).

- kolbot 사용처: 빌드·장비 판단(`builds/*.js`, nip 규칙), `Skill.cast` 시전 간격
- 표 읽는 법: `수치→프레임`. 예: `48→11` = 해당 수치 48% 이상이면 11프레임. 프레임이 작을수록 빠르다.
