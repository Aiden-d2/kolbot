# getUnit 범위 (사용자 측정)

`getUnit`으로 유닛이 잡히는 거리와 한 화면 범위를 잰 기록 (261104).

- kolbot 사용처: `getUnit` 탐색, `Attack.getMonsterCount`, 몬스터 수 세기

- 출처: 사용자 자료 `260413 getUnit range.txt`. 근거: 사용자 측정(260413).
- 원문 그대로. 같은 파일의 화면 해상도·야드 환산 부분은 `skill_range.md` 0절(야드)에 있다.

```
- = 마이너스 좌표에 있는 겟유닛
+ = 플러스 좌표에 있는 겟유닛

Y +45	//	49	//60	//62
Y -70	//	69	//56	//50

X +70	//	75	//53	//52
X -45	//	40	//66	//65

내좌표 기준 겟유닛
우측 84
좌측 75
상측 74
하측 84

중심좌표 기준 한화면

우상 = 30
좌상 = 30
우하 = 30
좌하 = 30

상 = 28
하 = 30
좌 = 18
우 = 18

가장큰 맹점은 x/y 값이 모두변하는 곳에서는 디스턴스가 크게 계산됨
```
