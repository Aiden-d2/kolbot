# 렐름 다운 (Battle.net 게임 생성 제한, 대기열, 렐름·캐릭터 다운)

Battle.net의 IP당 게임 생성 제한과 봇 수·게임 길이별 대기열 결과, 렐름·캐릭터 다운 대처 (261104).

- 환경: 사용자 환경은 Battle.net이다(사용자 결정 261104).
- kolbot 사용처: `D2BotLead.dbj`·`D2BotFollow.dbj`(게임 만들기·대기), `tools/OOG.js`, `StarterConfig.MinGameTime`(`D2BotLead.dbj`, 최소 게임 시간)

## 렐름 다운과 캐릭터 다운 (클래식)

- 출처: 카오스큐브 "디아블로2 정보 총정리"(https://www.chaoscube.co.kr/board/d2-ccbook/-318) 본문, 가져온 날 261104. 근거: 웹 미검증. 원문 그대로.

> 렐름다운 : 일시적으로 렐름이 다운되는 현상 10~30분 사이 조인(지속해서 로그인 시 접속되는 시간은 늘어나니 주의)
> 캐릭다운(방다운) : 일시적으로 방생성 실패 , 특정 캐릭터 조인 실패 5분 정도 뒤에 조인(다운된 캐릭터를 제외한 다른 캐릭터와 다른 계정은 참가됨)
