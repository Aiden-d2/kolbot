# Attack 대조표: 이전 코드 vs 현재 브랜치

- 비교 대상
  - 이전: `a40271a`의 `Attack.clear`, `clearList`, `scanList`, `setPosition` (리팩터링 전 마지막 업로드)
  - 현재: 브랜치 `claude/attack-docs` (main `b463c6b` + 260928 수정: Angle/Detour 판정을 setPosition으로, 접근 정렬 바깥 링 우선, 해머 게이트 0x5, idle 5회)
- 방법
  - 두 코드를 같은 모의 환경(Node, 엔진 함수 흉내)에 올려 같은 지형·몹 배치에서 나란히 실행
  - 지형: 벽(0x5), 짧은 벽(모서리), 강(0x1만)
  - 이동: walkTo·teleportTo·moveTo 호출과 우회 길이를 기록
  - 모의 파일: 세션 scratchpad `cmp/harness.js`, `gate_cases.js`, `loop_cases.js`, `hammer_test2.js`
- 한계
  - 실제 지형과 엔진 판정(checkCollision, getPath, 이동 성공 여부)은 흉내다. 인게임 확인이 필요하다.
  - 대조는 여기 적은 상황만 확인한다. 적지 않은 상황의 동일성은 보장하지 않는다.
- 분류
  - **A** 결함 수정 (의도한 차이)
  - **B** 합의된 변경
  - **=** 이전과 같음
