# Attack 대조표: 이전 코드 vs 현재 브랜치

- 비교 대상
  - 이전: `a40271a`의 `Attack.clear`, `clearList`, `scanList`, `setPosition` (리팩터링 전 마지막 업로드)
  - 현재: 브랜치 `claude/attack-docs` (main `b463c6b` + 260928 게이트 복원)
- 방법
  - 두 코드를 같은 모의 환경(Node, 엔진 함수 흉내)에 올려 같은 지형·몹 배치에서 나란히 실행
  - 지형: 벽(0x5), 짧은 벽(모서리), 강(0x1만)
  - 이동: walkTo·teleportTo·moveTo 호출과 우회 길이를 기록
  - 모의 파일: 세션 scratchpad `cmp/harness.js`, `gate_cases.js`, `loop_cases.js`
- 한계: 실제 지형과 엔진 판정(checkCollision, getPath, 이동 성공 여부)은 흉내다. 인게임 확인이 필요하다.
- 분류
  - **A** 결함 수정 (의도한 차이)
  - **B** 합의된 변경
  - **C** 이전과 다르고 아직 합의 확인이 필요한 것
  - **=** 이전과 같음

## 6. 합의 확인이 필요한 항목 (C)

|---|---|---|
| C1 | HP 스킵 측정 구간. 이전은 첫 타 **뒤** HP 기준(4타분), 현재는 합류 시점 기준(5타분)이라 조금 덜 스킵한다 | 이전과 같게: 기준 HP를 첫 시전 뒤에 기록 (1줄) |
