### 데이터 (d2reference 브랜치 `mpqdata/`)

- 읽는 법: `git fetch origin d2reference` 후 `git show origin/d2reference:mpqdata/excel/<파일>`. 탭 구분, 인코딩은 latin-1로 읽으면 된다.
- `experience.txt`: 1열 레벨, 2~8열 직업별 누적 경험치, 끝 열 `ExpRatio`. **줄 N의 값 = N+1레벨에 도달하는 누적 경험치**(한 칸 밀려 있다. 예: 줄 89 = 1,618,470,619 = 90레벨 도달값, 줄 98 = 3,520,485,254 = 99레벨). 그래서 L레벨 → L+1레벨 필요 경험치 = 줄 L − 줄 L−1. `ExpRatio`는 70레벨 이상 경험치 감소 비율(/1024, 예: 90 = 61, 95 = 15, 99 = 5). 앞쪽에 `MaxLvl` 줄과 0레벨 줄이 있다.
- `monlvl.txt`: 몬스터 레벨별 기본 수치. 경험치 열 `XP`·`XP(N)`·`XP(H)`와 `L-XP`·`L-XP(N)`·`L-XP(H)`. `L-` 열이 확장팩용으로 보인다(추정, 확인 필요).
- `monstats.txt`: 열 번호(1부터) `Id`=1, `hcIdx`=2, `MinGrp`=26, `MaxGrp`=27, `Level`=32, `Level(N)`=33, `Level(H)`=34, `boss`=88, `noRatio`=150, `Exp`=159, `Exp(N)`=172, `Exp(H)`=185. 몬스터별 경험치 %와 무리 크기.
- `superuniques.txt`: `Superunique`·`Name`·`Class`·`hcIdx`·`MinGrp`·`MaxGrp`(미니언 수)·`TC` 등.
- `levels.txt`: 열 번호 `Id`=2, `Act`=4, `SizeX`·`SizeY`=8·9(나이트메어 10·11, 헬 12·13), `MonLvl1Ex`~`MonLvl3Ex`=60~62, `MonDen`=63(N 64, H 65), `MonUMin`·`MonUMax`=66·67(N 68·69, H 70·71), `MonWndr`=72, `mon1`=75~, `nmon1`=86~, `umon1`=96~, `LevelName`=121. 중간에 `Id`가 빈 "Expansion" 줄이 있다.
- 지역 이름은 kolbot `Pather.getAreaName` 이름을 쓴다(사용자 결정 261105). `levels.txt` `LevelName`과 28곳이 다르다(`tc.md` 1절 아래 설명).
- 몬스터 레벨 규칙(나이트메어·헬 = 지역 레벨, 보스는 `monstats` 레벨, 유니크 +3, 챔피언 +2)은 `tc.md` 1절에 있다(1.14d 역어셈블로 확인한 것).

### 계산 순서 (Claude 제안 미결정)

1. 데이터에서 몬스터별 기본 경험치(난이도·레벨별)를 만든다.
2. D2MOO로 배수·인원수·파티 분배·감소 규칙을 확인하고, 웹 자료와 대조한다.
3. 바알런(웨이브 5번 + 바알)·디아런(봉인 3곳 + 디아블로)을 레벨 90~98, 인원 1명·8명으로 계산한다. 지금 `experience.md`의 표(평균 레벨 95 가정)와 같은 조건으로도 계산해 대조한다.
4. 지역 추정: `levels.txt` 밀집도·유니크 무리 수 × 지역 크기. 바깥 지역은 `SizeX`·`SizeY`, 미로 지역은 `lvlmaze.txt`(방 수)를 쓴다. 지도에 따라 달라 대략치만 나온다.
5. 결과를 `experience.md`에 넣는다. 출처 불명 표는 대조 결과에 따라 남길지 지울지 사용자에게 묻는다.

## 노트 작성 방식 (이번 검토에서 사용자가 요구한 것, 261105)

- 핵심만: 공식이면 공식, 사유면 사유. 원문 전문·긴 서술은 넣지 않는다(필요하면 git 기록으로 찾는다).
- 표를 쓰면 범례를 같이 둔다. 이름·기호·계산식을 생략하지 않고, 사용자가 표만 보고 해석할 수 있게 한다.
- 섞인 표는 종류별로 나눈다. 같은 설명은 한 번만 쓴다.
- 데이터로 확실히 틀린 것은 지운다. 판정할 수 없는 것은 남기고 "미확인"으로 표시한다.
- 값마다 근거(데이터 / 코드 / 웹 미검증 / 추정)를 적는다.
- 노트만 바꾸는 커밋·병합도 사용자 요청 뒤에 한다(CLAUDE.md 1절).
