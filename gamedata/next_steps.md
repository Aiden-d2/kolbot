# 다음 할 일 (미검증·미결 목록)

gamedata 노트 중 검증되지 않았거나 결론이 나지 않은 항목. 항목마다 내용, 출처(검증할 때 다시 볼 곳), 확인에 필요한 것을 적는다. 확인이 끝나면 해당 노트에 반영하고 여기서 지운다.

## 노트 작성 방식 (사용자 결정)

- 핵심만: 공식이면 공식, 사유면 사유. 원문 전문·긴 서술은 넣지 않는다(필요하면 git 기록으로 찾는다).
- 검증된 내용에는 원본 출처·옮겨 온 경위·이력을 적지 않는다. 검증되지 않은 것은 이 노트에 출처와 함께 둔다.
- 표를 쓰면 범례를 같이 둔다. 이름·기호·계산식을 생략하지 않고, 표만 보고 해석할 수 있게 한다.
- 섞인 표는 종류별로 나눈다. 같은 설명은 한 번만 쓴다.
- 데이터로 확실히 틀린 것은 지운다. 판정할 수 없는 것은 남기고 "미확인"으로 표시한다.
- 노트만 바꾸는 커밋·병합도 사용자 요청 뒤에 한다(CLAUDE.md 1절).

- **카오스 생추어리 날개 일반 몬스터 수**: 넓이로 추정한 상한(벽 등이 빠지지 않음).

- **웨이브 2 1런 값 1,883,220**: 맞는 조합이 없다(웨이브 구간 경계에 다른 웨이브 몬스터가 섞인 것으로 보이나 확인 안 함).

## item_mods.md

- **staff mod 굴림**: D2MOO 1.10f 코드. 1.14d에서 같은지는 사용자 판단. 아이템 형식 0일 때 부르는 `sub_6FC55060`은 읽지 않았다.
- **staff mod 주장**(인벤 "아이템의 오토모드와 스태프모드에 관한 정보", https://www.inven.co.kr/board/diablo2/5734/5298):

  - 같은 기술 탭의 스킬 3개가 다 붙지는 않는다(오브 제외). D2MOO 굴림에 탭을 보는 조건이 없다(1.14d 미확인).
- **소켓 관련 주장**(사용자 그림 `socket.png`, 카오스큐브, 무한의공갈): "매직, 레어, 유니크, 세트, 크래프트 등은 적용되지 않음 / 투척 무기는 소켓이 뚫리지 않음 / 드랍되는 아이템의 소켓은 숨렙을 따라가나 노멀은 3개, 나이트는 4개의 제한".
- **라주크 퀘스트 소켓 수**: "노멀(흰색) = 최대 소켓, 매직 = 1~2(무작위), 레어·유니크 = 1". 출처: 카오스큐브 "디아블로2 정보 총정리" 본문.
- **에테리얼**(카오스큐브 "에테리얼(무형)에 관한 고찰!", penny♡, https://www.chaoscube.co.kr/board/d2-commu-lab-lab/944029, 그리고 카오스큐브 늘비 도표):
  - 에테리얼 50%는 방어력 증가%보다 먼저 붙는다(1.09 또는 1.10부터).
  - 슈페리어 방어력 = ⌊(최고 방어도 + 1) × (100 + 방상%) / 100⌋, 슈페리어 에테리얼 = ⌊⌊(최고 방어도 + 1) × 3/2⌋ × (100 + 방상%) / 100⌋.
  - 큐브 소켓 버그(1.11 이후): 에테리얼 갑옷·방패를 큐브로 소켓 뚫으면 50%가 한 번 더 붙는다.
  - 확장팩 아이템에만 있고, 링·아뮬렛, 세트, 페이즈 블레이드, 활·석궁에는 없다(활·석궁은 옛 버전 주장으로 보임).
  - 수리 불가, 내구 약 절반(예: 50 → 27), 슈페리어 에테리얼은 내구 보너스 뒤에 줄어듦. 발견 시 내구 꽉 참, 수량 아이템은 최대 수량이 아님. 용병이 들면 내구가 닳지 않음.
  - 룬워드·임뷰는 에테리얼 유지, 크래프트하면 에테리얼이 사라짐. 상점에 팔면 값이 크게 떨어지고 되살 수 없음.
- **매직 접사 레벨**: D2MOO 1.10f 코드. 1.14d에서 같은지 확인하지 않았다.
- **그랜드 참 라이프 41~45**: 원래 글은 아이템 레벨 89부터라고 했고, "매직 접사 레벨" 식으로는 91이다.
- **큐빙으로 만든 참은 접사 결정 방식이 드랍과 다르다**(원래 글 주장).
- **매직 찬스**(카오스큐브 "매직 찬스 (매찬)의 작동 원리", Malic, https://www.chaoscube.co.kr/board/d2-commu-lab-lab/944044):
  - 실효 매직 찬스: 유니크 = MF × 250 / (MF + 250), 세트 = MF × 500 / (MF + 500), 레어 = MF × 600 / (MF + 600), 매직 = MF. 그 등급의 확률 배수 = 1 + 실효 / 100(일반 지식, 원래 글의 수치와 맞음).
  - 매직 찬스는 TC가 정해진 뒤 등급을 정할 때만 쓰이고, 등급은 유니크 → 세트 → 레어 → 매직 → 슈페리어 → 노멀 → 저품질 순으로 확인한다.
  - 강등: 유니크·세트로 정해졌는데 그 아이템이 없거나 레벨이 안 되면 유니크 → 내구 3배 레어, 세트 → 내구 2배 매직.
  - 앞 등급에서 뽑힐수록 뒤 등급은 배수만큼 오르지 않아, 최소 등급이 매직인 몬스터는 MF가 높을수록 매직 비율이 준다.
  - 필요: 1.14d 품질 판정 코드(`exe_1.14d.md` "품질 판정" `0x5586DB`~)와 대조.
- **우버 디아블로**(카오스큐브 "클래식 전용 우버(애니참) 획득 정보", Aliase, https://www.chaoscube.co.kr/board/d2-commu-lab-lab/941820): 상점에 조던을 팔아 서버(게임 IP)마다 누적 수가 차면(보통 80~120개) "Diablo walks the earth"가 뜨고 같은 IP의 헬 게임에 나온다. 한 게임에 한 번. 나오는 곳은 슈퍼유니크·보스 자리. 애니힐러스는 한 캐릭터에 1개.
- **헬파이어 토치**(카오스큐브 "횃불(헬파이어토치) 획득 정보(클래식)", Aga, 인터넷 아카이브 2023-09-25 사본): 열쇠 큐브는 액트5에서, 포탈 3곳 중 하나가 열림(한 자리에서 여러 번 열면 겹칠 수 있음). 우버 메피스토·디아블로·바알이 토치를 떨군다. 토치 스킬 +3. 열쇠·토치 거래 가능, 토치는 한 캐릭터에 1개, 스탠다드·래더 구분 없음.
