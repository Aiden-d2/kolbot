# 렐름 다운 (Battle.net 게임 생성 제한, 대기열)

Battle.net의 IP당 게임 생성 제한과 봇 수·게임 길이별 대기열 결과.

- 환경: 사용자 환경은 Battle.net이다.
- kolbot 사용처: `D2BotLead.dbj`·`D2BotFollow.dbj`(게임 만들기·대기), `tools/OOG.js`, `StarterConfig.MinGameTime`(`D2BotLead.dbj`, 최소 게임 시간)
